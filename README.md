# NPL_2026_Autumn
# Список задач:
## Параллельность:
1) Реализация паттерна Worker Pool (либо Manager-Worker +- одно и то же)
2) Релизация паттерна Producer-Consumer 
3) Реализация параллельной сортировки на основе паттерна разделяй и властвуй
4) Реализация параллельного умножения матриц

## Алгоритмическая задача 
1) Поиск в глубину через рекурсию (Lua)
2) QuickSort через рекурсию (Haskell)
3) https://neetcode.io/problems/longest-repeating-substring-with-replacement/question?list=neetcode150 (ML)
4) https://neetcode.io/problems/search-2d-matrix/question?list=neetcode150 (Scheme)

## ввод/вывод в консоль/файл
1) Консольная программа с тестом / "приключением" (Prolog)
2) Реализация команды grep (Perl)
3) Интерактивный консольный дневник с поиском по дате (Lisp)
4) Фильтрация логов по каким-то ключевым словам, например в логе работы тестирования ищем все запуски тестов (ODIN)

## клиент-серверное взаимодействие
1) ЭХО-сервер, который в зависимости от настройки/клиента по-разному обрабатывает сообщения и отправляет обратно (Groovy)
2) Игра про подземелье с множеством игроков. (Erlang)
3) Сервер с тестом, который рассылает вопросы и принимает ответы от клиентов. Выводит итоговый процент. (Elixir)
4) Калькулятор накоплений удалённый (OCaml)

## конвертация данных из одного формата в другой
1) CSV -> HTML (Ruby)
2) INI -> JSON (Nim)
3) CustomTXT -> JSON (файл определённого вида, который парсится и переводится в json, например, список игроков и их характеристик) (F#)
4) JSON -> CSV (D)
